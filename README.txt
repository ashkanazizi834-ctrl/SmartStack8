# SmartStack 8 برای اندروید

## محتویات
- `index.html`: خود اپ
- `manifest.webmanifest`: مشخصات نصب PWA
- `sw.js`: ذخیره‌ی فایل‌ها برای اجرای آفلاین پس از اولین بارگذاری
- `icons/`: آیکون‌های اپ

## نصب روی اندروید
PWA باید از یک وب‌سایت HTTPS باز شود؛ باز کردن مستقیم `index.html` از داخل فایل‌ها باعث نصب PWA نمی‌شود.

راه ساده با GitHub Pages:
1. وارد GitHub شو و یک حساب کاربری بساز یا وارد حساب خودت شو.
2. یک مخزن (Repository) جدید بساز.
3. فایل‌های داخل این پوشه را در ریشه‌ی مخزن بارگذاری کن.
4. در Settings → Pages، گزینه‌ی Deploy from a branch را انتخاب کن و شاخه‌ی main و پوشه‌ی /(root) را ذخیره کن.
5. پس از انتشار، نشانی سایت را با Chrome در گوشی اندرویدی باز کن.
6. از منوی سه‌نقطه‌ی Chrome گزینه‌ی Install app یا Add to Home screen را بزن.

پس از اولین بارگذاری موفق، اپ برای استفاده‌ی آفلاین هم فایل‌های اصلی را نگه می‌دارد.

## نکته درباره محتوا
مکالمه‌ها تمرین‌های کوتاه و تألیفی بر اساس موضوع هر درس هستند؛ متن کامل گفت‌وگوهای کتاب در این پروژه کپی نشده است.
